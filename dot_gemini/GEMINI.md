# Global Rules

## Version Control

- Always use Jujutsu (`jj`) instead of Git (`git`) for all version control operations.
- Prefer `jj` commands (e.g. `jj status`, `jj diff`, `jj log`, `jj describe`, `jj commit`, `jj new`, `jj bookmark`, `jj git push`, `jj git fetch`).
- Do not run `git` commands unless explicitly requested or when a tool strictly requires raw git.
